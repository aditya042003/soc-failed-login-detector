SOC Failed Login Detector

About My Project

I made this project using Python to learn basic cybersecurity.
This program reads login records and checks failed login attempts. It also shows the IP address and gives an alert if an IP has 5 or more failed attempts.

Tools Used
* Python
* VS Code
* Login log file

How It Works
1. It reads login records from a file.
2. It checks which logins failed.
3. It counts failed attempts from each IP address.
4. It shows an alert for suspicious IP addresses.

What I Learned
* Python loops and if-else
* Reading files in Python
* Working with IP addresses
* Counting failed login attempts
* Basic security log analysis

Future Improvements
I want to add more features to this project and learn more about how SOC analysts detect suspicious activity.
